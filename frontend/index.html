Transfer Money
Calls stored procedure: CALL transfer_money(sender, receiver, amount)
⚙️ Procedure Info

The transfer_money stored procedure atomically:

  1. Validates sender has sufficient balance
  2. Deducts amount from sender
  3. Credits amount to receiver
  4. Inserts a Transaction record
  5. Triggers detect_high_amount if amount > ₹20,000
  6. Triggers audit_balance_update on each balance change

⚠ Amounts > ₹20,000 automatically create a HIGH-risk Fraud Alert and raise the sender's risk_score.
